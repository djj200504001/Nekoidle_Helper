# Nekoidle Helper 本地增强版 1.42.1

基于仓库提交 `0c084b5894123c4b9af4f090c391adbe100da120`，增加研究队列、任务自动领取和产出库存显示。安装文件为根目录的 **银河猫娘放置小助手.user.js**；`src`、`tools` 和 `tests` 供维护使用，无需额外安装。

## 研究队列

- 在研究所每个可升级项目的「开始研究」旁增加「加入研究队列」按钮；当前有研究进行时也能继续加入。
- 队列位于当前研究下方，显示顺序、目标等级、各项材料消耗，以及合计预留量、背包数量和剩余可用量。支持移出排队项目。
- 点击一次排入一次升级。同一项目连续加入时，按未来等级分别计算成本，包含材料品阶变化；当前正在研究的一级已经扣过材料，不会重复预留。
- 加入时检查 **背包数量 − 已有队列预留量**，不足时提示，材料补足后才能开研。只记录成本与预留额度，不发送开研请求，也不扣材料。服务器在队首真正开始研究时扣款，原生消息处理器负责更新背包。
- 预留是插件的本地记账，其他游戏操作仍可使用这些材料。执行前会重新核对队首材料，不足时等待补充，保持队列顺序。
- 到期后自动提交完成研究，确认结算后再开始队首。请求未确认时先查询状态；如果查询发现开研已经成功，则刷新角色快照以核对扣款，避免按旧库存继续排程。
- 账号分别保存队列和设置，刷新页面后保留；换浏览器或清除站点数据不会同步恢复。

## 任务与产出库存

- 自动接受满足前置条件的主线、支线任务，以及额度允许的劳务派遣。
- 自动领取已完成任务奖励，遵循游戏“任一目标完成即可领取”的规则；等级目标读取角色当前等级。自动奖励通过顶部通知反馈，手动领奖保留原有弹窗。
- 梳毛、采集、生产、烹饪详情的产出与额外奖励旁显示「背包：数量」，约每两秒刷新，也随页面装饰更新。按实际物品 ID 和同强化等级统计背包数量。
- 「队列产出」按相同物品及强化等级汇总当前行动与待执行行动的剩余次数，使用实际加工倍数和料理份数。随机掉落和越级失败按期望值计算。不限次行动没有固定总量，会单独标出。
- 队列产出是按当前等级、熟练度和加成估算的毛产出，假设材料足够，不扣除队列会消耗的同名物品。材料用完、加成变化或手动调整队列都会影响实际产量。
- 生产详情的消耗栏显示「剩余可用」，按背包数量减去进行中和排队行动的计划用量计算。统计剩余次数、加工倍数、省料加成及烹饪替代食材。计划用量达到库存或存在使用该材料的不限次行动时显示 0。随机结算会影响实际用量，显示随背包和队列更新。
- 生产消耗栏也显示「队列产出」，与产物栏中同一物品、同一强化等级的预计产出一致。预计产出独立显示，剩余可用量仍以当前背包为基础。

## 设置与运行条件

游戏设置 →「其他」→「小助手」提供五个独立开关，默认开启。开关分别控制队列自动开研、自动领取已完成研究、自动接受任务、自动领取任务奖励，以及产出库存、队列产出和生产材料可用量的显示。研究开关位于设置页。全部功能受原有总开关控制。

自动操作需要游戏页面保持打开、账号在线且连接可用。标签页处于后台或电脑休眠时，浏览器可能延迟定时检查；关闭页面不会在服务器上继续执行本地队列。多个同源游戏标签页采用本地租约协调，接管时先核对数据；队列开研中的条目确认之前不能编辑。

安装时在 Tampermonkey 中用此文件更新同名主脚本并刷新游戏页。此次保留上游更新地址；后续安装上游版本可能覆盖本地增强，建议保留本文件备份。
